# Sistema de Reservas - Centro de Endoscopia

Aplicación web para gestionar citas de endoscopia con calendario gráfico, 3 turnos diarios y control de disponibilidad.

## Características

- **Calendario visual** interactivo
- **3 turnos por día**:
  - Mañana: 08:00
  - Mediodía: 11:00
  - Tarde: 14:00
- Formulario de datos del paciente al seleccionar día + turno
- Bloqueo automático de horarios ya reservados
- Almacenamiento local (demo) – fácil de conectar a base de datos real
- Diseño limpio y profesional orientado a entorno médico

## Cómo probar

1. Abre `index.html` en el navegador
2. Selecciona un día disponible
3. Elige un turno libre
4. Completa el formulario del paciente
5. La reserva se guarda y el turno queda ocupado
